# [DX-002] Command Line Interface

## Context & Goal
**As a** [Government Affairs Developer](../../personas.md#government-affairs-developer),
**I want to** interact with PyGovPub through a command-line interface,
**So that** I can quickly test functionality, debug issues, and automate tasks without writing code.

## Acceptance Criteria
- [x] Core Commands
  - `pygovpub config` - Set up API keys and preferences
  - `pygovpub health` - Run health checks
  - `pygovpub congress bill search` - Search for bills
  - `pygovpub congress bill get` - Retrieve specific bills
  - `pygovpub govinfo package get` - Retrieve specific documents
  - `pygovpub status` - Check API status and rate limits

- [x] Command Features
  - Consistent command structure
  - Shell completion support
  - Help documentation
  - Version information
  - Debug mode via verbose option

- [x] Output Formats
  - JSON output (with --format json option)
  - XML output option (with --format xml option)
  - Table/text format for readable display (default)
  - Export to file option (with --output option)
  - Verbose mode for debugging (with --verbose option)

- [x] User Experience
  - Clear error messages
  - Color-coded output (via Rich library)
  - Configuration persistence
  - Consistent parameter naming

## Technical Context
- Must work in various shell environments
- Should support automation/scripting
- Needs to handle large data sets
- Must maintain security
- Should work with CI/CD tools
